# SwiftPay UI/UX Capstone — GATEWAY Program 2026

A UX case study built for the GATEWAY Program 2026 (Mastercard Foundation & CcHUB), General Gig Work Course capstone. This project redesigns SwiftPay, a fintech app experiencing a 60% user drop-off rate, with a focus on rebuilding user trust across the core journey.

## The Problem

SwiftPay users were abandoning the app at three key points — login, home dashboard, and money transfer — due to a trust deficit rather than a purely usability issue. Sensitive verification requests, exposed account data, and transactions with no confirmation step were driving users away before they ever completed a transfer.

## What's Inside

- **3 High-Fidelity Screens** — Login, Home, and Transaction, each redesigned around specific trust-building cues
- **AI-Assisted Research (The Engine Room)** — User personas and a UX friction audit generated using a structured RTCROS (Role, Task, Context, Rules, Output, Style) prompt framework
- **Workflow Map** — the design process: User Research → AI Persona/Audit → Wireframing → Figma Prototyping → Quality Audit
- **User Flow Map** — the path a user takes from opening the app through completing a transaction
- **Consultative Proposal & Data Privacy Audit** — a client-facing breakdown of the problem, findings, and how sensitive user data is protected across the redesign

## Key Trust Fixes

- 🔒 Added contextual reassurance and an encryption notice on the Login screen
- 🕒 Added a "Last login" timestamp and location line on the Home dashboard
- 👁️ Added a balance-masking toggle to protect sensitive account data from shoulder-surfing
- 💵 Added a full cost breakdown (amount, fee, total) and encryption notice before every transaction is confirmed
